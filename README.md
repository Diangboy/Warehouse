# 📦 Система управления складом (Warehouse Management System)

🦅 **Минималистичное десктопное приложение** для быстрого и безопасного учёта товаров.

[![Framework](https://img.shields.io/badge/UI-Raylib-fbfb00.svg?style=flat-square)](https://www.raylib.com/)
[![Database](https://img.shields.io/badge/Database-SQLite3-003b57.svg?style=flat-square&logo=sqlite)](https://www.sqlite.org/)
[![Environment](https://img.shields.io/badge/OS-Arch%20Linux-1793d1.svg?style=flat-square&logo=arch-linux)](https://archlinux.org/)

Легковесное и высокопроизводительное приложение для складского учёта. В проекте реализована многопользовательская архитектура с жесткой изоляцией данных: каждый пользователь имеет доступ только к собственному каталогу товаров.

---

## 🔥 Ключевые особенности

* **🔒 Изоляция данных на уровне SQL:** Полная независимость учетных записей благодаря реляционным связям в SQLite3 (`WHERE user_id = ?`). Пользователи не могут видеть или изменять чужие товары.
* **⚡ Скорость ввода данных (UX):** Интерфейс оптимизирован для быстрой работы без мыши. Поддерживается навигация через `Tab` и мгновенное сохранение записей по нажатию `Enter`.
* **🎨 Четкая типографика:** Использование системного шрифта `JetBrains Mono` с включенной аппаратной билинейной фильтрацией (`TEXTURE_FILTER_BILINEAR`), что убирает пиксельные "лесенки" и снижает нагрузку на зрение.
* **🧹 Чистый код без "мусора":** Никакой скрытой телеметрии, мгновенный запуск и минимальный размер скомпилированного бинарника.

## 🛠 Стек технологий и окружение

* **Язык программирования:** C++17 (GCC / Clang)
* **Графический фреймворк:** Raylib (на базе OpenGL)

## 📖 Руководство пользователя (User Guide)

### 1️⃣ Авторизация (Вход / Регистрация)
При запуске приложения открывается защищенное окно авторизации.

* **Регистрация:** Нажмите кнопку **"Switch Mode"** внизу экрана, чтобы перейти в режим `REGISTER`. Введите уникальный логин, пароль и нажмите **CONFIRM** (или клавишу `Enter`).
* **Вход:** В режиме `LOGIN` введите свои данные. Система определит ваш уникальный `user_id` и подгрузит из базы данных *только ваши товары*.

### 2️⃣ Главный экран (Панель управления)
Рабочее пространство разделено на две функциональные зоны:
* **Левая панель (Список товаров):** Инвентарная таблица в реальном времени с колонками **NAME** (Название), **QTY** (Количество) и **PRICE ($)** (Цена).
* **Правая панель (Добавление):** Форма для быстрого внесения новых позиций в базу данных.

### 3️⃣ Управление товарами (Скоростной режим)
Чтобы добавить товар, не прикасаясь к мышке:
1. Кликните на поле **Product Name** (или переключитесь на него).
2. Введите название $\rightarrow$ Нажмите `Tab` $\rightarrow$ Введите количество $\rightarrow$ Нажмите `Tab` $\rightarrow$ Введите цену.
3. Нажмите `Enter`. Данные мгновенно запишутся в SQL и отобразятся в левом списке.
4. **Удаление:** Чтобы стереть позицию, просто нажмите красную кнопку **DEL** напротив нужного товара.

## ⚙️ Установка и сборка

<details>
<summary><b>📦 Установка системных зависимостей</b></summary>

В **Arch Linux** убедитесь, что у вас установлены необходимые библиотеки для разработки:
```bash
sudo pacman -S raylib sqlite gcc cmake make
# Клонирование репозитория
git clone https://github.com/Diangboy/Warehouse.git
cd Warehouse

# Создание директории сборки и компиляция
mkdir build && cd build
cmake ..
make

# Запуск приложения
./Warehouse
```
</details>
